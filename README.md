#  Login Validation Project (JavaScript)

## Project Description
This project is developed using JavaScript to gain hands-on experience in front-end development. It implements basic login validation by checking whether the username and password are correct.

The project demonstrates fundamental authentication concepts and form validation techniques, including form validation, error handling, and user feedback. It helps in understanding how real-world login systems validate user input before sending data to the server.

---

##  Login Validation Features

-  Validates user email/username using proper format (e.g., email pattern)  
-  Ensures password meets required conditions:
  - Minimum length  
  - At least one uppercase letter  
  - At least one lowercase letter  
  - At least one number  
  - At least one special character  
-  Displays error messages for invalid inputs  
-  Prevents form submission if validation fails  
-  Provides instant feedback to improve user experience  

---

##  Technologies Used

- **HTML** – Structure of the login form  
- **CSS** – Styling and layout  
- **JavaScript** – Validation logic and interactivity  
- **Regular Expressions (Regex)** – Pattern matching for email and password  

---

##  Learning Outcomes

- Understanding of client-side form validation  
- Implementation of basic authentication logic  
- Improved JavaScript DOM manipulation skills  
- Better handling of user input and error messages
